# digitalia-module-digitalia_muni_nfield_agent

A custom field type that records information about agents as defined by the Czech Core Metadata Model (people or organizations).

Features:
- ORCID lookup widget that prefills name and orcid
- ROR lookup widget theat prefills name and orcid (organization, affiliation)
- Possibility to record contact email
- Custom display widget for customizing which metadata to display and how
- orcid and ror link is displayed under icon of the identifier
